## ⚙️ Setup Instructions

### 1. Clone repository

git clone https://github.com/Kanchana-86/study-assistant.git
cd study-assistant

---

### 2. Create virtual environment

python3 -m venv venv
source venv/bin/activate

---

### 3. Install dependencies

pip install flask requests python-dotenv

---

### 4. Add API Key

Create `.env` file:

API_KEY=your_api_key_here

⚠️ Do NOT share this file

---

### 5. Run the app

python app.py

Open in browser:
http://127.0.0.1:5000

---
